Datasets Used in the Project
This directory contains documentation and source information for the datasets selected for the project:
Deep Learning-Based Detection of Sybil Attacks in Vehicular Networks (VANETs)

1. VeReMi Extension
Source: https://github.com/josephkamel/VeReMi-Dataset
Dataset type: VANET misbehavior-detection dataset
Purpose: To study vehicle communication behavior and identify data relevant to detecting Sybil attacks.
Data format: JSON files
Status: Dataset source identified. Relevant features and attack labels are being verified.
