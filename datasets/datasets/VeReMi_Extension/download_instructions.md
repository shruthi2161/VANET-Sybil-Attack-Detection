VeReMi Extension — Download Instructions
Official Dataset Source

The VeReMi Extension dataset is available through the following repository:

https://github.com/josephkamel/VeReMi-Dataset

The repository README provides the dataset download link.

Download Steps

1. Open the official GitHub repository.
2. Locate the dataset download link in its README.
3. Open the linked MEGA folder.
4. Browse the available scenarios.
5. Download the required dataset files.
6. Extract the downloaded archive.
7. Inspect the JSON records and ground-truth information.

Scenario Inspection

The following scenario folders were observed during initial inspection:

- `ConstPos_0709`
- `ConstPos_1416`
- `ConstSpeed_0709`
- `ConstSpeed_1416`
- `DataReplaySybil_0709`
- `DataReplaySybil_1416`

The `DataReplaySybil` folders appeared empty during our initial inspection. Their contents must be verified before using them.

Important

The availability of Sybil-specific labels and the suitability of each scenario must be confirmed by inspecting the actual dataset records.
