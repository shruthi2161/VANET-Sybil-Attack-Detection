VeReMi Extension Dataset
Dataset Overview:
                VeReMi Extension is a dataset designed for the evaluation of misbehavior detection in Vehicular Ad Hoc Networks (VANETs).
Source
                -GitHub repository: https://github.com/josephkamel/VeReMi-Dataset
                -Datataset download: Available through the download link provided in the repository README.
Purpose in Our Project
                 This dataset is selected as a primary data source for studying vehicle communication behavior and identifying information relevant to Sybil attack detection.
Data Format:
                 The downloaded dataset contains JSON files, including vehicle communication records and a ground-truth file.
Relevant Information to Inspect
The following information will be checked in the available records:
       -Vehicle position and GPS-related information
       -Vehicle speed and movement
       -Communication-related features
       -Ground-truth labels
       -Availability of Sybil attack records
Current Status:
                 The dataset source has been identified. The available files and labels are being inspected to confirm their suitability for Sybil attack detection.
Note:
                The presence of Sybil-specific attack labels has not yet been confirmed. Dataset suitability will be finalized after inspecting the ground-truth information.
